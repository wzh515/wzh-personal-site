# 个人展示网站 · 产品需求文档（PRD）

> 版本：v1.0　|　更新日期：2026-10-19　|　状态：待开发

---

## 1. 产品概述

本项目是一个**纯前端静态个人展示网站**，用于集中展示个人的专业形象、技能能力、项目成果与博客文章。网站面向招聘方、潜在合作者与行业同行的第一印象窗口，因此核心目标是：**快速建立专业信任、清晰呈现能力与作品、方便进一步联系**。

产品形态为单页应用（SPA）+ 多详情页的静态站点，不依赖后端服务器。所有数据（个人信息、技能、项目）以本地 JSON 管理，博客以 Markdown 文件管理，通过 Vite 构建为静态资源后可部署至任意静态托管平台（Vercel / Cloudflare Pages）。

**核心体验关键词**：深色科技感、星空氛围、简洁现代、加载轻快、多端自适应。

## 2. 用户目标

### 2.1 目标用户

| 用户角色 | 核心诉求 |
| --- | --- |
| 招聘方 / HR | 快速了解候选人的背景、技能栈、项目经验，获取联系方式与简历 |
| 技术负责人 / 面试官 | 评估技术深度（项目、博客、代码能力） |
| 潜在合作者 / 同行 | 了解作品、阅读博客、建立连接 |
| 站主本人 | 低维护成本地持续更新内容，展示个人品牌 |

### 2.2 用户目标（按优先级）

1. **P0**：3 秒内理解"我是谁、做什么、擅长什么"，一眼找到项目与联系方式。
2. **P0**：在 375px 手机与 1440px 桌面都能获得完整、无错位的浏览体验。
3. **P1**：通过博客与项目详情页深入了解个人能力与思考。
4. **P1**：一键复制邮箱 / 提交联系表单，完成转化（获得联系）。
5. **P2**：站主能通过"新增 Markdown 文件"零成本发布新博客。

### 2.3 成功指标

- 首屏（Hero）在 3G 网络下 2 秒内可交互。
- 移动端星空粒子动画帧率 ≥ 50fps。
- 新增博客文件后刷新页面，列表自动出现新文章（无需改代码）。
- 联系表单提交后 100% 有成功或失败反馈。

## 4. 设计要点

### 4.1 配色（深色主题）

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景色 | `#0B0F1A` | 全局主背景 |
| 文字主色 | `#E6EAF2` | 正文与标题 |
| 文字次要 | `#9AA3B2`（约） | 辅助说明、日期、次要信息 |
| 强调色 | **可配置**（默认 `#6C8CFF` 或站主自定） | 按钮、链接、高亮、进度条 |
| 边框/分割线 | `rgba(230,234,242,0.08)` | 卡片描边、分隔线 |
| 卡片背景 | `rgba(230,234,242,0.03)` ~ `0.06` | 半透明卡片，叠加星空之上 |

> 强调色通过 `src/config/theme.ts` 或 Tailwind `@theme` 定义，实现"一处配置、全局生效"。
> 文字对比度需满足 WCAG AA：正文 ≥ 4.5:1，大字号/图形 ≥ 3:1。

### 4.2 星空粒子背景

- 使用 **Canvas 2D** 绘制，非 DOM 元素（性能优先）。
- 粒子特性：**缓慢闪烁**（透明度周期性变化）+ **视差效果**（鼠标/滚动轻微位移，背景层比前景层移动慢）。
- 粒子数量随设备自适应：移动端自动减少（约桌面端 40%~50%）。
- 尊重 `prefers-reduced-motion`：用户系统开启"减弱动画"时，粒子停止漂移与闪烁（可静态显示或完全关闭）。
- 通过 `requestAnimationFrame` 驱动，页面不可见时暂停动画（`document.visibilitychange`）。

### 4.3 响应式布局

| 断点 | 布局 |
| --- | --- |
| `< 640px` | 单列布局 |
| `640px ~ 1024px` | 两列布局 |
| `> 1024px` | 三列布局 |

- 内容最大宽度 **1200px**，居中，两侧留白。
- 卡片网格：`grid-cols-1` → `sm:grid-cols-2` → `lg:grid-cols-3`。
- 验收硬指标：**375px 视口无横向滚动条**。

### 4.4 导航

- **吸顶毛玻璃导航**：`position: sticky` + `backdrop-blur` + 半透明背景。
- 桌面端：横向菜单（首页 / 关于 / 技能 / 项目 / 博客 / 联系）。
- 移动端（< 640px）：**汉堡菜单**，点击展开折叠菜单。
- 点击锚点链接平滑滚动到对应 section（`scroll-behavior: smooth` + 导航高度偏移补偿）。

### 4.5 动效

- **圆角统一 12~16px**：卡片 16px，按钮/标签 12px。
- **统一缓动函数**：定义全局 CSS 变量 `--ease: cubic-bezier(0.4, 0, 0.2, 1)`，所有过渡/动画统一使用。
- 过渡时长统一 200~300ms，入场动画 300~500ms。
- 元素入场使用轻量淡入 + 上移，避免过度炫技影响可读性。

## 5. 验收标准

| # | 验收项 | 标准 | 验证方式 |
| --- | --- | --- | --- |
| 1 | 375px 移动端无横向滚动条 | 375px 视口下 `document.documentElement.scrollWidth ≤ 375px` | DevTools 375px 模拟 + 真机 |
| 2 | 移动端星空粒子帧率 ≥ 50fps | 低端移动设备上动画稳定 ≥ 50fps | `requestAnimationFrame` 计数 / Performance 面板 |
| 3 | 新增 Markdown 博客自动更新 | 新增 `.md` 文件后，列表页自动出现新文章 | 新增文件 → 刷新 → 列表出现 |
| 4 | 联系表单提交成功/失败反馈 | 提交后展示明确的成功或失败提示 | 空校验、格式错误、成功路径分别验证 |
| 5 | 深色模式文字对比度达标 | 正文/标题对比度满足 WCAG AA | 对比度检测工具（如 Lighthouse / axe） |
| 6 | 响应式三档布局正确 | 单列 / 两列 / 三列随断点切换 | 三档视口截图比对 |
| 7 | 键盘导航可用 | Tab 可遍历所有可交互元素，焦点可见 | 纯键盘操作走查 |
| 8 | 图片有 alt 属性 | 所有 `<img>` 有描述性 `alt` | 代码审查 / axe 扫描 |
| 9 | 平滑滚动 & 吸顶导航 | 锚点点击平滑滚动，导航滚动后吸顶 | 手动走查 |
| 10 | 博客详情 TOC + 代码高亮 | TOC 可跳转，代码块高亮正确 | 手动走查含代码的文章 |
